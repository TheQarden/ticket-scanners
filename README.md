# 📷 QR Сканер с проверкой

> Навел камеру - сразу показывает что зашифровано

Простой и быстрый веб-сканер QR-кодов, который работает прямо в браузере. Никаких установок, никаких серверов - всё происходит на вашем устройстве.

## ✨ Возможности

-  Мгновенное распознавание QR-кодов
-  Работает на телефонах и компьютерах
-  Копирование результата в буфер обмена одной кнопкой
-  Красивый современный дизайн с анимацией сканирования
-  Автоматическое переключение на основную камеру

## 🎯 Для чего использовать

- Проверка билетов и пропусков
- Сканирование QR-кодов с чеков
- Расшифровка любой закодированной информации
- Быстрое считывание ссылок и контактов

## 🤔 Как пользоваться

1. Нажмите кнопку **"ЗАПУСТИТЬ КАМЕРУ"**
2. Разрешите доступ к камере (браузер попросит)
3. Наведите камеру на QR-код
4. Результат появится автоматически — можно скопировать

## 🛠 Технологии

- HTML5 / CSS3
- JavaScript (ES6+)
- [jsQR](https://github.com/cozmo/jsQR) — библиотека для распознавания QR
- WebRTC — доступ к камере
